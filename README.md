# 🛡️ HandleVault Official Assets

This repository serves as the centralized hosting hub for lightweight UI widgets and text-based promotional tickers used across the **HandleVault Ecosystem** (GitVoice, Invoice Studio, Resume Studio, Pixel Art Studio, Moonlit Beads, and Kusina AI).

## 📂 Included Assets & Features
- 🚀 **Text-Based Ticker & Promos** — Engaging text notifications with emojis for wellness breaks (*☕ Water, CR & Stretch muna!*) and app/store promotions without needing heavy video files.
- `widget.js` — A lightweight, standalone client-side script that injects the non-intrusive bottom-right text notification widget with rotation and countdown features.

## 🔗 Integration
To connect any of the HandleVault apps to this centralized asset hub, simply include the following script before the closing `</body>` tag of your app's `index.html`:

```html
<script src="[https://handlevault-official.github.io/kofi-files/widget.js](https://handlevault-official.github.io/kofi-files/widget.js)"></script>
