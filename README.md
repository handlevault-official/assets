# 🛡️ HandleVault Official Assets

This repository serves as the centralized hosting hub for shared media assets and lightweight UI widgets used across the **HandleVault 5-App Suite** (GitVoice, Invoice Studio, Resume Studio, Pixel Art Scaler, and Moonlit Beads).

## 📂 Included Assets
- `promo-ads.mp4` — A sleek, 5-second multi-app teaser video combined with a universal wellness/break reminder (*Break Time: Water, CR, Stretch*).
- `widget.js` — A lightweight, standalone client-side script that injects the non-intrusive bottom-right promo widget on a 4.5-hour interval.

## 🔗 Integration
To connect any of the HandleVault apps to this centralized asset hub, simply include the following script before the closing `</body>` tag of your app's `index.html`:

```html
<script src="https://YOUR_GITHUB_USERNAME.github.io/handle-vault-assets/widget.js"></script>
