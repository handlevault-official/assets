# 🛡️ HandleVault Official Assets

This repository serves as the centralized hosting hub for shared media assets and lightweight UI widgets used across the **HandleVault Ecosystem** (GitVoice, Invoice Studio, Resume Studio, Pixel Art Studio, Moonlit Beads, and Kusina AI).

## 📂 Included Assets
- `videos/promo-ads-1.mp4` — Sleek promo teaser videos combined with a universal wellness/break reminder (*Break Time: Water, CR, Stretch*).
- `widget.js` — A lightweight, standalone client-side script that injects the non-intrusive bottom-right promo widget with rotation and countdown features.

## 🔗 Integration
To connect any of the HandleVault apps to this centralized asset hub, simply include the following script before the closing `</body>` tag of your app's `index.html`:

```html
<script src="[https://handlevault-official.github.io/kofi-files/widget.js](https://handlevault-official.github.io/kofi-files/widget.js)"></script>
